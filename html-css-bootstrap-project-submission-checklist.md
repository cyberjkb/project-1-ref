WAES - Full Stack Bootcamp

HTML CSS Bootstrap Project – Submission Checklist

LO1: Front-End Design & User Experience

Website Design
[ ] Three-page website, with each page designed to differentiate structure and style.
[ ] Main navigation menu is present and functional.
[ ] Content is structured and organised logically.
[ ] Semantic use of HTML tags (header, nav, main, footer, etc.).

Accessibility & Visual Design
[ ] Appropriate colour contrast.
[ ] Alt text for all non-text elements.
[ ] No WCAG errors detected.
[ ] CSS colour variables used for consistent styling.
[ ] WebP images used instead of JPEG/PNG where (optional).
[ ] Lazy loading applied to images (e.g. loading="lazy").

Responsive Layout
[ ] Layout adapts to different screen sizes.
[ ] No major errors or loss of functionality on resize.

User Experience
[ ] Information organised using UX principles (clear headers, prioritised info).
[ ] Headers convey structure and hierarchy.
[ ] Information is easy to find.
[ ] User can initiate and control actions (e.g. play/pause media).
[ ] Immediate feedback provided for user actions (e.g. submitting a contact form).


LO2: Testing & Validation

Code Validation
[ ] Custom HTML passes W3C validation.
[ ] Custom CSS passes W3C Jigsaw validation.
[ ] No validation errors or warnings.

Performance Testing
[ ] Lighthouse performance test completed.
[ ] Accessibility, Best Practices, SEO, and Performance scores reviewed.

LO3: Cloud Deployment
[ ] Final version deployed to a cloud platform (e.g. GitHub Pages).
[ ] Deployment matches development version (no discrepancies).
[ ] Git & GitHub used for version control.
[ ] Clear commit history with comments.
[ ] Clean, commented code.
[ ] All commented-out code removed before deployment.
[ ] Internal links and interactive elements function correctly.

LO4: Documentation & Maintainability

Documentation (README.md)
[ ] Live link to deployed website (placed at the top of README).
[ ] Table of contents.
[ ] Website’s purpose
[ ] Brief descriptions of features and user benefits provided.
[ ] Deployment procedure.
[ ] Screenshots of all pages on both desktop and mobile views.
[ ] Screenshots of passed HTML, CSS, and Lighthouse performance tests.
[ ] Bugs / Errors Section.
[ ] Proper attribution for any external code / image / video sources.
[ ] Declaration of use of AI.
[ ] Colour palette image included (optional).
[ ] Wireframes included (optional).
[ ] Planned future updates (optional).
